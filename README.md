# distance-graphs-with-AI

Are we able to improve lower estimates in the Hadwiger-Nelson problem for R^n, n=2, 3, 4, 5, ... with latest LLMs? Certainly, in some cases they can... 

- $\chi(Q \times R) \geq 4$: [23-vertex graph](QxR_4col/) found with GPT-6 Astra. Can be verified by hand in 10 minutes. 

- $\chi(R^4) \geq 10$: [328-vertex graph](R4_10col/) found with GPT-6 Astra. Currently can be verified in ~50 hours with [Kissat](https://github.com/arminbiere/kissat) or another SAT solver.
